# Kordra

Universal, extensible download manager built with Rust. Early development.

**Development policy:** build, test and package exclusively on GitHub-hosted GitHub Actions runners. No personal servers are used as development environments, runners, or staging.

See [architecture](docs/ARCHITECTURE.md), [roadmap](docs/ROADMAP.md), and [Kordra-Agent](https://github.com/KordraProject/Kordra-Agent).

> Pre-alpha: functionality is under active development. Do not expose the API to untrusted networks.
