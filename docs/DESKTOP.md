# Kordra desktop (Tauri 2, pre-alpha)

Tauri desktop now wraps the existing single Kordra Web interface and includes a built headless `kordra-daemon` as a platform sidecar.

- Runs the daemon on `127.0.0.1:8079` when no local daemon is already listening.
- Owns and stops only the subprocess it created; never kills a preexisting local Kordra process.
- Stores app data using the OS app-data directory; uses OS Downloads for files, falling back to local data.
- The same Web UI is compiled for Desktop with `VITE_KORDRA_API_BASE=http://127.0.0.1:8079`. The headless API allows the two Tauri app origins via a restricted CORS layer.
- All packages are produced in GitHub-hosted Actions: Windows NSIS `.exe` / MSI and portable ZIP; Linux DEB / RPM / AppImage (x64 initially).

Limitations: the localhost API has no authenticated desktop session, the app currently reuses any listener on the local port, and closed-window background operation/tray is not implemented. Do not expose the daemon to untrusted networks. Portable archives are initial binaries bundled with a sidecar, not a fully portable data-directory mode yet.

Build-time icons are generated by `apps/desktop/scripts/make_icons.py` from standard Python, without storing font assets.
